## App privacy

Select **No, we do not collect data from this app**.

Floatdoro has no account, analytics, advertising, tracking, third-party SDKs,
or network service. Timer state, tasks, preferences, and focus history remain
in the app's local sandbox. System notifications are scheduled on the Mac.

## Screenshots

Upload the four JPEG files from the appropriate localization directory in
numeric order. Every file is 2880 × 1800, 16:10, and has no alpha channel.
Apple accepts one to ten Mac screenshots.

The `raw` directory contains the unframed real application captures. The final
screenshots are generated by:

```sh
swift scripts/build_app_store_screenshots.swift
```

## Before submitting

1. Merge and deploy the `docs` directory through GitHub Pages.
2. Confirm that the privacy, support, and marketing URLs load publicly.
3. Create the app record with the values above.
4. Archive build `8` with version `1.0.2`.
5. Validate and upload the archive from Xcode Organizer.
6. Wait for processing and select the build under macOS 1.0.2.
7. Complete App Privacy, age rating, availability, and pricing.
8. Add the English and Russian metadata and screenshots.
9. Paste the review notes and choose manual release.
10. Submit for review.
